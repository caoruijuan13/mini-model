# 从小模型开始，逐步理解和实践机器学习

本项目采用“输入 → 模型 → 输出”的方式，一次学习一个问题，在手写和实验中补齐机器学习知识。

当前阶段是逻辑回归二分类。主线代码和学习记录见 [01_logistic_regression](projects/01_logistic_regression/)。后续阶段将在当前阶段完成并冻结后再单独建立。

## 当前阶段

详细学习内容、公式、实验结果和限制见 [learning_notes.md](projects/01_logistic_regression/learning_notes.md)。

## 快速开始

```bash
python3 projects/01_logistic_regression/main.py
```

## 路线

逻辑回归完成并冻结后，再进入字符 bigram、字符级 MLP 和最小 Transformer。
