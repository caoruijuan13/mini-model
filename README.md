# 从小模型开始，逐步理解和实践机器学习

本项目采用“输入 → 模型 → 输出”的方式，一次学习一个问题，在手写和实验中补齐机器学习知识。

## 训练范式

项目中的训练任务可以采用不同的数据监督方式：

- 监督学习：训练数据同时提供输入 `x` 和目标标签 `y`。模型用 `y` 计算损失，再更新参数。
- 自监督学习：原始数据本身可以自动产生训练目标，不需要人工逐条标注。例如把序列向右移动，用下一个元素作为当前元素的预测目标。

两者都需要定义明确的输入、目标、损失和评估方式；区别在于目标标签的来源，而不是是否使用某一种模型或损失函数。后续项目应在各自文档中说明具体的数据格式和训练流程，通用概念统一以本总说明为准。

当前阶段是逻辑回归二分类。主线代码和学习记录见 [01_logistic_regression](projects/01_logistic_regression/)。后续阶段将在当前阶段完成并冻结后再单独建立。

## 项目定位

每个阶段都围绕一个可以独立观察的“输入 → 核心逻辑 → 输出”闭环展开。项目目录不仅是代码位置，也对应一个明确的机器学习逻辑或工程功能。

| 项目 | 核心逻辑 | 主要功能 | 输入 → 输出 | 训练与验证重点 |
| --- | --- | --- | --- | --- |
| [01_logistic_regression](projects/01_logistic_regression/) | 线性函数、sigmoid、二元交叉熵、梯度下降 | 二分类概率预测 | 两个数值特征 → 类别概率和分类结果 | 标签、loss、梯度方向、参数更新、验证集 early stopping、测试集泛化 |
| [02_char_bigram](projects/02_char_bigram/) | 字符 bigram、教学/真实语料对照、原始/改进采样 | 下一字符预测和序列生成 | 一个上下文字符 → 下一字符概率分布 | 自监督目标构造、平滑、困惑度、temperature、top-k |
| [03_char_trigram](projects/03_char_trigram/) | 字符 trigram、bigram backoff、改进采样 | 真实语料下一字符预测和生成 | 两个上下文字符 → 下一字符概率分布 | 稀疏上下文、验证集平滑选择、困惑度、temperature、top-k |

后续项目继续沿用这五个定位维度：

1. 核心逻辑：模型到底计算了什么；
2. 主要功能：模型解决什么问题；
3. 输入输出：一次调用接收和返回什么；
4. 训练方式：参数如何获得，目标从哪里来；
5. 验证重点：用什么测试证明实现和结果可信。

这样可以区分“学习一个模型逻辑”和“实现一个可使用功能”：训练、评估、保存属于模型生命周期功能，预测和生成属于运行时功能，测试则负责验证这些功能的边界和正确性。

## AI 学习范式地图

项目按训练目标和反馈来源进行主分类。一个项目可以同时拥有能力标签，例如“生成式”“序列建模”或“部署”，但主分类只回答：模型从什么数据和反馈中学习。

| 学习范式 | 核心特征 | 当前项目 | 后续占位 |
| --- | --- | --- | --- |
| 监督学习 | 输入和目标标签由数据集明确提供 | [01 逻辑回归](projects/01_logistic_regression/)：二分类 | 多分类、回归、结构化预测 |
| 自监督学习 | 从原始数据自动构造预测目标 | [阶段 02 字符 bigram](projects/02_char_bigram/)、[阶段 03 字符 trigram](projects/03_char_trigram/) | 字符级 MLP、Transformer、掩码建模 |
| 无监督学习 | 没有明确标签，直接学习数据结构或分布 | 暂无 | 聚类、降维、密度估计、表示学习 |
| 强化学习 | 通过环境反馈的奖励和惩罚学习行动策略 | 暂无 | 多臂老虎机、价值函数、策略优化 |

### 横向能力标签

以下内容不与上面的学习范式互斥，而是描述项目要实现的能力：

- 预测：输入样本，输出类别、数值或概率；
- 表示学习：把原始数据转换为有用的向量表示；
- 序列建模：利用前后顺序预测或生成序列；
- 生成式建模：学习数据分布并生成新样本；
- 决策与控制：根据状态选择行动并优化长期收益；
- 评估：用 loss、准确率、困惑度或任务指标检验效果；
- 工程化：模型保存、加载、批处理、服务化、监控和复现。

当前项目的归类不是最终目录结构。新增项目时，先登记所属主范式，再标注横向能力，并补充“核心逻辑、主要功能、输入输出、训练方式、验证重点”五项定位。这样可以明确哪些知识已经覆盖，哪些仍然只是路线占位。
