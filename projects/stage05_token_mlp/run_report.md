## 收敛与过拟合

训练 loss 在 2000 次更新中持续下降，但验证 loss 在约 743 次更新后开始上升：

| 参数更新次数 | 训练 loss | 验证 loss |
| ---: | ---: | ---: |
| 0 | `3.702089` | `3.717832` |
| 500 | `2.304698` | `2.870597` |
| 743 | `2.126930` | `2.814298` |
| 1000 | `1.990881` | `2.842437` |
| 1500 | `1.759886` | `2.949878` |
| 2000 | `1.556267` | `3.104800` |

这不是梯度停止，而是短语料上的过拟合。当前只有 522 个训练样本和 190 个不同的训练上下文，模型却有 2184 个参数；验证集中约 `21.2%` 的上下文没有在训练集中出现。训练流程因此使用验证 loss 保存并恢复最佳参数，而不是保存最后一步参数。

## 与阶段 03 trigram 对照

| 模型 | 验证 perplexity | 测试 perplexity |
| --- | ---: | ---: |
| 阶段 03 trigram + bigram backoff | `21.679572` | `17.423710` |
| 阶段 05 Token MLP | `16.681468` | `17.704684` |

两者都使用同一份 652 字符语料和顺序切分，但不能视为完全同构的算法对照：阶段 05 只使用训练文本建立包含特殊 token 的 vocabulary，并把 BOS/EOS 纳入样本；阶段 03 使用计数、平滑和 backoff。当前结果显示 MLP 的验证 perplexity 更低，而测试 perplexity 与 trigram 接近，不能据此宣称 MLP 已稳定优于 trigram。

## 固定 seed 生成样例

使用恢复后的最佳参数、`seed=7`、默认 temperature 和 top-k：

```text
ess cof the ine tits ar aont ine ir ifinererene to of of or the one the thatse int athe on the te af
```

样例证明模型可以沿滚动上下文完成生成，并表现出部分字符和短词模式；它不是语言质量提升的主要证据。

- 固定 seed 的生成结果可复现；

- 当前全项目测试为 `32 passed`。

## 证据边界

- 当前公共领域语料只有 652 个字符，验证集和测试集都很小；
- 结果只来自一个固定随机种子，不包含方差估计；
- test split 在实现和诊断期间已经被多次观察，因此当前测试指标是探索性记录，不再属于严格未观察的 sealed test；
- 后续超参数和结构选择只应使用训练集与验证集，新的最终泛化结论需要额外未观察语料；
- 增大隐藏层或上下文可能加重当前数据稀疏和过拟合，下一步优先进入阶段 06 的训练工程，而不是用当前 test 指标继续调参。
