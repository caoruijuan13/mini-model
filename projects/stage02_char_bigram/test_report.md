## 2. 执行方式

```bash
PYTHONPATH=projects/stage02_char_bigram python3 -m pytest -q projects/stage02_char_bigram/tests
```

## 3. 测试用例

### 3.1 概率归一化

训练后检查概率矩阵每一行的和是否约等于 `1.0`。这验证每个当前字符对应的是合法的下一个字符分布。

### 3.2 验证集困惑度

在未用于统计的验证集上计算困惑度，并确认结果为有效值。这验证训练后的模型可以用于独立文本评估。

### 3.3 采样长度

要求 `sample(length=25)` 返回长度为 25 的文本，验证采样循环不会少生成或多生成字符。

### 3.4 保存和加载

将模型保存到临时 `npz` 文件后重新加载，检查词表和概率矩阵与原模型一致。这验证生成阶段可以复用训练阶段产物。

## 5. 测试结论

当前测试证明了计数、概率归一化、基本评估、采样和持久化的教学基线。

这些测试不证明生成文本具有语义质量，也不证明模型适用于更大的语料、未知字符或生产服务。
