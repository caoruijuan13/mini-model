# 07 学习顺序

1. 运行数据检查，手算输入/目标错位窗口；
2. 实现 `causal_mask()`，启用未来位置屏蔽测试；
3. 实现单头 scaled dot-product attention，确认权重归一化与 `weights @ V`；
4. 实现多头投影、拆头、合头和输出投影，检查形状与未来信息不泄漏；
5. 实现 LayerNorm、FFN、残差 block；
6. 实现 token/position embedding、多层堆叠、logits 与平均交叉熵；
7. 验证关键梯度后实现反向传播或明确选择自动求导依赖；
8. 接入 mini-batch、优化器、验证集选择、保存加载与逐 token 生成；
9. 完成真实语料运行报告和全部验收后，再更新总路线图。

每一步都应能回答：输入和输出形状是什么？当前位置能否读到未来？新增参数有哪些？测试是否能抓到一个具体错误？
