# 01 逻辑回归代码测试报告

## 1. 报告范围

本报告只描述自动化测试代码验证了什么，不记录某一次训练运行的具体指标。运行结果见 [run_report.md](run_report.md)。

测试代码位于 [tests/test_main.py](tests/test_main.py)。测试按以下层次组织：数据、数学函数、loss、梯度方向、完整训练和最佳参数恢复。

## 2. 执行方式

```bash
python3 -m pytest -q projects/01_logistic_regression/tests
```

## 3. 测试用例

### 3.1 数据测试

验证训练/验证/测试切分比例、特征和标签形状、标签是否为 0/1，以及固定 seed 是否产生相同数据。

这个测试保证输入数据可复现，也防止后续修改数据生成逻辑时破坏基本形状。

### 3.2 sigmoid 测试

验证输出是有限值、位于 0 到 1 之间、输入增大时输出不减，并且 `sigmoid(0)=0.5`。

### 3.3 二元交叉熵测试

将权重和偏置设为 0，此时 `z=0`、`p=0.5`，标签为 0 和 1 的平均损失应为 `log(2)`。

这是一个可以手工计算的基准，用来检查 loss 公式和实现是否一致。

### 3.4 梯度方向测试

设置 `x=1`、`y=1`、`p=0.5`。此时模型应该提高正类概率，因此要求 `w` 变大、`b` 变大且 loss 变小。

这个测试直接验证参数更新方向，而不是只看最终准确率。

### 3.5 完整训练测试

验证训练后的最佳验证集 loss 低于初始验证集 loss，并且测试集准确率超过 `0.8`。

### 3.6 最佳参数恢复测试

验证训练结束后，模型当前参数在验证集上的 loss 与训练过程记录的最佳验证集 loss 一致，确保 early stopping 或跑满最大轮数后不会保留较差的最后一组参数。
