# 01 逻辑回归设计报告

## 1. 项目目标

本项目通过一个完全可观察的二分类问题，学习机器学习的基本闭环：输入数据、模型前向计算、得到概率、计算损失、计算梯度、更新参数、验证泛化、测试最终结果。

重点不是追求模型复杂度，而是理解每一步为什么存在、输入输出是什么，以及如何通过测试确认实现正确。

## 2. 要解决的问题

给定一个包含两个数值特征的样本，判断它属于类别 `0` 还是类别 `1`。输入是 `x=[x0,x1]`，输出是 `P(y=1|x)` 和最终类别。

这是一个监督学习问题，因为每个输入样本都有一个真实标签 `y`。

## 3. 数据设计

每个样本包含两个来自标准正态分布的特征。数据生成器使用隐藏规则 `score = x0 + 0.8*x1 + noise`，再使用 `y = 1(score > 0)` 生成标签。

`noise` 用来模拟未观测因素，使决策边界附近的样本不完全确定。理想情况下，分类边界接近 `x0 + 0.8*x1 = 0`。

模型并不知道这个规则，只能通过 `x` 和 `y` 学习它。

数据随机打乱后按 `60%/20%/20%` 分为训练集、验证集和测试集。当前数据正负样本大致平衡，主要用于学习基础逻辑回归，不代表正样本只有 5% 的类别不平衡问题。

## 4. 模型设计

### 4.1 线性分数

模型先计算 `z = w0*x0 + w1*x1 + b`，向量形式是 `z = Xw + b`。其中 `w` 是权重向量，`b` 是偏置，`z` 是尚未转换成概率的 logit。

### 4.2 sigmoid 概率

模型使用 `p = sigmoid(z) = 1/(1+exp(-z))`，其中 `p` 表示 `P(y=1|x)`。

sigmoid 是单调递增函数，因此 `z` 变大时 `p` 变大，`z` 变小时 `p` 变小。

### 4.3 最终分类

当前使用 0.5 作为阈值：`p >= 0.5` 预测类别 1，否则预测类别 0。当 `p=0.5` 时 `z=0`，所以决策边界是 `w0*x0 + w1*x1 + b = 0`。

## 5. 损失函数设计

使用平均二元交叉熵：`L = -mean(y*log(p) + (1-y)*log(1-p))`。

当 `y=1` 时，损失是 `-log(p)`，模型需要提高 `p`；当 `y=0` 时，损失是 `-log(1-p)`，模型需要降低 `p`。

代码把概率限制在 `[1e-8, 1-1e-8]`，避免出现 `log(0)`，导致 `inf` 或 `nan`。

## 6. 梯度和参数更新

模型关系是 `w,b → z → p → L`。使用链式法则可得：`∂L/∂z = p-y`、`∂L/∂w_i = (p-y)*x_i`、`∂L/∂b = p-y`。

对整个批次取平均后，权重梯度是 `X.T @ (p-y) / n`，偏置梯度是 `mean(p-y)`。

梯度下降更新为：`w = w - learning_rate*gradient_w`，`b = b - learning_rate*gradient_b`。

因此，`p-y < 0` 时模型需要提高 logit，`p-y > 0` 时模型需要降低 logit。权重方向还受到对应特征正负的影响；偏置梯度不乘特征，因为 `∂z/∂b=1`。

## 7. 训练流程

每轮训练先用训练集计算概率和 `p-y`，然后计算权重与偏置梯度并更新参数；接着计算训练 loss 和验证集 `valid_loss`。

训练集用于更新参数，验证集用于观察泛化、保存最佳参数和 early stopping，测试集不参与参数更新，只在模型确定后进行最终评价。

## 8. 评价指标

当前基线使用二元交叉熵 loss 评价概率质量，使用 accuracy 评价 0.5 阈值下的分类结果。

如果研究正样本只有 5% 的场景，还需要增加 precision、recall、F1、PR-AUC、混淆矩阵和验证集阈值选择。

## 9. 主线文件

当前只保留 [main.py](main.py)，其中包含数据容器、数据生成、sigmoid、逻辑回归、loss、梯度更新、训练、验证和测试入口。

把这些内容放在一个文件中，是为了让学习者可以沿着一次执行路径读完完整逻辑。

## 10. 设计边界

- 合成数据只用于理解训练机制，不能代表真实任务能力。
- 当前实现是教学用 NumPy 代码，不是生产训练框架。
- 当前没有正则化、mini-batch、GPU、checkpoint 和自动求导。
- 模型解释描述模型的计算行为，不直接构成现实世界因果结论。
