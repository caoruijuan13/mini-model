# 01 逻辑回归运行结果报告

## 1. 报告范围

本报告记录一次完整训练运行，包括训练前数据状态、模型初始状态、训练过程和最终结果。

代码测试结果单独记录在 [test_report.md](test_report.md)，模型和训练设计记录在 [design.md](design.md)。

## 2. 运行方式

```bash
python3 projects/01_logistic_regression/main.py
```

## 3. 训练前：数据生成

本次运行使用：

| 项目 | 配置 |
|---|---|
| 总样本数 | 3000 |
| 数据随机种子 | 3 |
| 特征数 | 2 |
| 数据切分 | 60%/20%/20% |
| 训练集大小 | 1800 |
| 验证集大小 | 600 |
| 测试集大小 | 600 |

数据由以下隐藏规则生成：

```text
score = x0 + 0.8*x1 + noise
y = 1(score > 0)
```

数据生成后使用同一个随机排列同步打乱 `x` 和 `y`，再切分训练集、验证集和测试集。

### 3.1 数据形状

```text
train.x.shape = (1800, 2)
train.y.shape = (1800,)
valid.x.shape = (600, 2)
valid.y.shape = (600,)
test.x.shape  = (600, 2)
test.y.shape  = (600,)
```

### 3.2 类别比例

| 数据集 | 正样本比例 | 负样本比例 |
|---|---:|---:|
| 训练集 | 50.9444% | 49.0556% |
| 验证集 | 54.8333% | 45.1667% |
| 测试集 | 47.5000% | 52.5000% |

因此本次是近似平衡的二分类实验，不是正样本率 5% 的不平衡实验。

## 5. 训练过程

每一轮执行：

1. 使用训练集计算概率 `p`。
2. 计算误差 `p-y`。
3. 计算权重和偏置梯度。
4. 更新 `w` 和 `b`。
5. 计算训练集 loss。
6. 计算验证集 loss。
7. 保存验证集表现最好的参数。

本次运行最多训练 1000 轮，在第 738 轮触发 early stopping；验证集最佳参数出现在第 708 轮。

训练后参数约为：

```text
w = [4.700681, 3.826668]
b = 0.026580
```

## 6. 最终结果

| 指标 | 数值 |
|---|---:|
| 最佳验证集 loss | 0.176739 |
| 最佳轮次 | 708 |
| 停止轮次 | 738 |
| 最终训练集 loss | 0.193077 |
| 最终验证集 loss | 0.176739 |
| 测试集 loss | 0.181780 |
| 测试集 accuracy | 91.8333% |

程序最终输出的核心结果为：

```text
best_valid_loss = 0.176739
test_accuracy   = 0.918333
```

## 7. 结果解释

- 训练 loss 从约 `0.693` 降到约 `0.193`，说明参数更新有效。
- 验证 loss 从约 `0.694` 降到约 `0.178`，说明模型对未参与参数更新的数据也有所改善。
- 测试 loss 与验证 loss 接近，说明本次合成数据上没有明显的泛化崩溃。
- 权重不需要等于数据生成规则中的 `1.0` 和 `0.8`，因为模型优化的是概率损失，而不是直接复原生成公式。

## 8. 结果限制

- 当前数据正负样本大致平衡，不能据此判断正样本率 5% 时的效果。
- 只运行了一个随机种子，不能说明结果稳定性。
- 当前主要报告 accuracy 和交叉熵，没有报告 precision、recall、F1 或 PR-AUC。
- 合成数据结果不能代表真实数据表现。
- 当前结果是学习阶段基线，不是生产模型验收结论。
