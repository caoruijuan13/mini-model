# 10 测试报告（初始化）

运行命令：

```bash
python3 -m pytest -q projects/stage10_inference_serving/tests/test_stage10.py
```

当前结果：阶段 10 `29 passed`，全量 `142 passed`。原有 5 个加载测试覆盖构造时保留注入的模型与 tokenizer、指定路径只加载一次、加载错误传播，以及用临时推理文件恢复模型配置与词表。两个单条生成用例覆盖 BOS 起始、新增文本截取、EOS/长度结束原因和空提示。批量用例验证首条请求遇到 EOS 后仍返回所有输入的结果，并验证批量结果等于逐条调用 `generate()` 且按输入序号分配 seed。

流式测试验证调用后返回迭代器、在采样下一 token 前产出当前片段、暂停期间恢复模型状态、零长度和立即 EOS 时不产出文本，以及真实随机采样在相同 seed、temperature 和 top-k 下与非流式结果一致。

perplexity 测试验证每个目标 token 只计一次、长文本滚动上下文、每段文本独立添加 BOS/EOS、空文本仍评估 BOS→EOS、无效集合与元素类型被拒绝、错误 logits 被拒绝，以及模型异常后恢复原状态。

benchmark 测试验证加载冷启动、未预热首请求和预热后统计彼此分离；预热不进入正式统计，正式运行次数、生成 token 总数和吞吐正确，并报告延迟列表、均值、P50、P95、设备和工作负载。参数测试验证字符串形式的 prompts、非字符串元素、布尔值和越界运行次数会被拒绝。

生成与流式用例使用固定输出的教学模型；批量等价用例替换了底层采样函数。这些测试尚未验证已训练模型的实际生成质量、真正的张量批处理、服务接口、版本兼容诊断或性能指标。因此阶段 10 仍未完成验收。
