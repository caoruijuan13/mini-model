# 10 学习笔记

1. **模型文件与训练断点**：推理文件需要权重、结构配置和正确的 token ID 映射；恢复训练还需要优化器及训练进度。本阶段只使用前者。
2. **评估与生成**：perplexity 衡量固定目标 token 的预测概率；抽样文本用于观察生成行为，不能由一个样例推断整体质量。
3. **单条、批量和流式**：批量处理应保持每个请求的输入和采样语义；流式接口要定义新增片段、结束标志与最终文本的关系。
4. **冷启动与稳态**：加载文件和初始化运行时属于冷启动；预热后重复请求反映另一种耗时。报告须分别说明。
5. **吞吐与延迟**：吞吐关注单位时间处理量，延迟关注单个请求；必须同时记录输入长度、生成长度、批量大小和设备。

当前最小练习是用 `InferenceRuntime.load(path)` 从阶段 08 的推理文件恢复模型与词表，并确认这一过程无需训练语料。后续实现顺序及边界见 [设计](design.md)。
